The trading terminal that lives on your machine.

ZettaTrade is a cross-platform desktop terminal for crypto market data — Binance and Bybit feeds today, candles and the order book rendered with SkiaSharp, on Windows, macOS and Linux. It is AI-native: a Model Context Protocol server and client plus a local model answer with the live context of your screen — the cloud is optional. And it is local-first: the ledger is SQLite on your disk, logs are files, secrets live in the OS keyring and nothing phones home.

What's shipped

Only features that exist on the current tree get a card here — the same rule the docs follow: no vaporware on the hero, and every claim below traces to a shipped row on the board.

Charts

Candlestick charting with zoom, pan and a crosshair OHLC readout; VWAP and volume-profile overlays; SMA, EMA, WMA, RSI, MACD, Bollinger and ATR ship as in-tree indicator plugins.

Order book

A live ladder from the venue's public stream, with the cumulative-depth chart next to it. Click a level and the order ticket opens prefilled; trades stream into the tape.

Portfolio

Balances and positions panels, a persisted order journal (SQLite via EF Core), and a PnL engine: realized and unrealized accounting, win rate, profit factor and the equity curve — all computed from the local ledger.

Alerts

Price and percent-move alerts with a manager: they watch the stream, fire toasts and land in a notification history you can browse.

AI assistant

One consent toggle feeds a token-bounded snapshot of the live workspace to a local Ollama model. The built-in MCP server (Zetta) and an MCP client put tools over the same paper lane, behind the same risk gates.

Download

Alpha builds travel as self-contained per-OS archives attached to GitHub Releases: win-x64, osx-x64 and osx-arm64 as zip, linux-x64 as tar.gz, with a SHA-256 sums file (zettatrade-<version>-sha256.txt) attached next to them. The delivery pipeline builds and attaches these automatically on every version tag — the artifacts contain the app and nothing else: no user data, no credentials.

Local-first and safety-first

Local-first is the architecture, not a privacy pitch: configuration, the SQLite ledger, file logs and the secret store (DPAPI on Windows, Keychain on macOS, the Secret Service on Linux, with an app-created encrypted file as the fallback) all live on your machine. There is no telemetry, and the only thing allowed on stdout is the MCP protocol itself.

The shipped trading backend is the paper simulator: simulated fills against live market prices, an in-memory demo balance, and never real funds or exchange keys. Every order passes risk validation before it can execute, and anything flagged high-risk asks for explicit human confirmation — including orders an AI agent places through the MCP tools. Real venues are reachable in testnet mode by a configuration change, and the status-bar chip (Paper · Testnet · Live) makes the lane unmistakable at a glance; the testnet trading loop itself is a queued row on the board, so nothing on this page claims it.
